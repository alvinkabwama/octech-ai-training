# Week 0 + Week 1 Lessons and Exercises Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Week 0 (git + setup) and Week 1 (calling a model) lessons, starters and stubbed
tests, plus the shared OpenRouter helper and `make check` / `make live` runners.

**Spec:** `docs/superpowers/specs/2026-11-11-octech-ai-training-design.md` (section 10 is binding)
and the task brief in the conversation (lesson format, test policy, helper API).

## Global Constraints

- OpenRouter is the only provider; every call goes through `exercises/common/llm.py`.
- Exercise tests never call a model. `make test` / `make ci` stay green on `main`:
  default pytest runs `mini_edrms/tests` and `exercises/common/tests` only.
- Starters are unfinished on purpose (TODO raises `NotImplementedError` or placeholder values),
  so `make check WEEK=<N>` fails until the trainee does the work.
- Reference solutions live in git-ignored `solutions/week-<N>/` and are never committed.
- Synthetic data only; no HFB/client names or content (the OpenRouter guide is committed as-is).
- Python >= 3.10. Conventional commits, no attribution lines, no push, no merge.

## Design decisions

- **Runner:** `scripts/run_week.py {check,live} <N> [--starter DIR]`, so make and PowerShell
  share one cross-platform entry point. `check` runs `pytest exercises/week-<N>-*/tests`;
  `live` runs `<starter>/live.py`. `--starter` (env `EXERCISE_STARTER_DIR`) points the tests
  or the live run at another folder, which is how the trainer verifies `solutions/week-<N>`.
- **Loading starters in tests:** fixture `load_starter(name)` in `exercises/conftest.py` imports
  `<week>/starter/<name>.py` by path under a unique module name.
- **No-network guarantee:** an autouse fixture in `exercises/conftest.py` replaces
  `openai.OpenAI` with a class that raises. Fixture `fake_llm` replaces `llm.get_client` with
  a scripted fake client that records every `chat.completions.create` call. Stubbing below
  `chat()` means the tests pass however a trainee imports `chat` / `ask`.
- **Retry:** 3 attempts in total, sleeping 5s then 10s between them. A 20s sleep after the
  last attempt would only delay the error. On giving up, raise `LLMError` naming the free-tier limits.
  The SDK's own retries are off (`max_retries=0`) so ours are the only ones.
- **Fallback list:** at most 3 models (`MAX_MODELS`). `OPENROUTER_MODEL` replaces the first
  default and `model=` goes first. Duplicates are removed.
